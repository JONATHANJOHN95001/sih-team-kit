Start Setup Toolkit Project Gotchas

The web toolkit, nothing to install

These all run in a browser tab, so there is no download and no setup beyond signing in. Please use the same Google account for every one of them, because sharing a design or a database project between us later becomes painful if we are scattered across different logins.

AI you can chat with

Gemini is our main assistant for thinking through problems and drafting text. There is no desktop app for Windows, so the browser is the only option.
ChatGPT works well as a second opinion. Please use the website rather than any desktop app you find, because the ones in the Windows package manager are all unofficial copies.
Google AI Studio is where your Gemini API key comes from, and where you can check how much of your daily quota is left.
Groq runs open models at several hundred words a second, which is fast enough that the answer appears the moment you stop typing. Worth wiring in if any part of the demo calls a model live on stage, because waiting in silence in front of judges feels much longer than it is. The free tier has an hourly limit, so do not point your whole app at it.

Research and sources

Perplexity answers with its sources attached, which is exactly what we need for the presentation. Use Search mode rather than Work mode, as Work burns through the free allowance quickly.
NotebookLM lets you upload a long government PDF and then ask questions about it, answering with page numbers so every claim we make can be traced back.
The SIH portal carries the official rules, the timeline, and the published problem statements.

Design and prototyping

Stitch takes a plain-English description of a screen and designs it properly, including a mobile version. Remember to switch the toggle from App to Web before you generate anything.
Bolt takes a description of an entire app and builds a rough working version, which is genuinely useful in the first hour when we are staring at an empty folder.
Excalidraw is where we will draw the architecture diagram. Judges consistently respond to one clear picture of how the system fits together.
Photopea is a free Photoshop that runs in a tab, for any image editing the deck needs.
A DESIGN.md file in the repo is the cheapest way to stop the app looking like four different apps. Write your colours, fonts and spacing rules into one markdown file, and every AI agent you use reads the same rules instead of inventing its own. Stitch can generate a design system straight from it.

Components you paste in saves hours

shadcn/ui is the single biggest time saver here. You copy a component's code into your own project rather than installing a library, so buttons, dialogs and forms look finished immediately, and because the code is now yours, you can edit it on the spot instead of fighting someone else's settings.
Aceternity UI is the same copy-paste idea for animated sections. Use it on the landing screen and nowhere else. Animation everywhere reads as a template, but one well-placed moving element makes the whole thing look considered.

Database and backend

Supabase is our database and login system. One important detail: a free project goes to sleep after seven days of inactivity, so whoever owns it should open this dashboard on the morning of the demo to wake it up.
Neon is a second Postgres database we can use for throwaway experiments, and unlike Supabase it wakes itself up automatically.
GitHub holds our repository, and the submission link comes from here.

Indian data and languages our edge

Bhashini is the Government of India's own AI language platform, built by MeitY, covering 22 Indian languages for speech and translation. It is free with no rate limit, and using the government's own infrastructure at a government hackathon is an angle most teams will not have considered.
data.gov.in holds real government datasets covering agriculture, health, disaster management and more. Seeding our app with genuine data rather than invented rows is exactly what separates a prototype from a demo, and when we cite it we should name the dataset and year rather than just the portal.

Deploy, demo and compute

Cloudflare Pages gives us a free permanent web address for the finished app, which is far better on a slide than localhost.
Google Colab provides a free GPU in the browser, which we will need if any part of our solution involves training a model.
Vercel does the same job as Cloudflare Pages, and either is fine, so pick one and stop thinking about it. The reason to prefer Vercel with four people pushing at once is that every push gets its own preview link, so you can send someone a working URL of your half without disturbing what is on the main address. The free plan is for non-commercial projects, which a hackathon entry is.
github.dev opens VS Code inside a browser tab, which is a useful escape route if someone's laptop dies on the day.

Free student perks worth claiming

Both of these verify your student status using your college details, and both can take a few days to come through, so it is worth starting them now rather than the night before.

Google AI Plus free 12 months

This gives you 400 GB of storage and full Gemini access, free for a year. Claim it using your JAIN college mail.

When it asks you for your school, you must select "JAIN (Deemed-to-be University)" from the dropdown list that appears. Typing the name and moving on will not work.

Claim AI Plus

GitHub Student Pack free

This one includes JetBrains Ultimate, $200 of DigitalOcean credit, $100 of Azure credit, a free domain name, and 180 hours a month of Codespaces, which is cloud development that runs perfectly well even on a slow laptop.

Two things in the pack are easy to miss. It includes GitHub Copilot Pro free for as long as you are a student, which most people never switch on, so turn it on inside VS Code once the pack is approved. It also includes a free domain for a year through Namecheap, and a real web address on the slide reads better than a long github.io link.

Set your GitHub profile location to Bangalore before you apply, because a mismatch between your location and your college is the most common reason applications get rejected.
