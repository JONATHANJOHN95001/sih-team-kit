How the 24 hours actually go

Nobody is going to be typing code line by line. Our job is to direct the AI clearly and then check its work carefully, which is a different skill and a much faster one.

01Research the problemFind real government figures we can put on a slide and defend when a judge questions them. 02Design the screensDescribe a screen in plain English and get a designed layout back in seconds. 03Build it · prompt to taskDescribe what we want and the agent writes it straight into the project files. 04Review and run itRead what changed, fix what is wrong, then open it in a browser and confirm it works. 05Store the dataDatabase and login, hosted online, with nothing heavy running on our laptops. 06Record the demoThe moment it works. A recording that plays reliably beats a live demo that crashes. 07Build the deckSlides written as a text file and exported to PDF. This is scored, not decoration.
