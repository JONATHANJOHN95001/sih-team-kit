How the 24 hours actually go

Nobody is going to be typing code line by line. Our job is to direct the AI clearly and then check its work carefully, which is a different skill and a much faster one.

01Research the problemFind real government figures we can put on a slide and defend when a judge questions them.
02Design the screensDescribe a screen in plain English and get a designed layout back in seconds.
03Build it — prompt to taskDescribe what we want and the agent writes it straight into the project files.
04Review and run itRead what changed, fix what is wrong, then open it in a browser and confirm it works.
05Store the dataDatabase and login, hosted online, with nothing heavy running on our laptops.
06Record the demoThe moment it works. A recording that plays reliably beats a live demo that crashes.
07Build the deckSlides written as a text file and exported to PDF. This is scored, not decoration.

The setup — six steps

Work your way down the page in order. Mark each step done as you finish it and your progress will be saved on this device, so you can stop partway and pick up later.

There are three downloads here. Click each button below, run the installer it gives you, and click Next through every screen — the default options are all correct and none of them need changing.

Node.js pick LTS Git VS Code

To explain what each of these actually does: Node.js is what runs all the AI tools we install in step 2, so nothing else will work without it. Git is how six of us can edit the same code without overwriting each other's work. VS Code is the editor where we will actually see and change the project.

Please restart your PC now. Windows will not recognise the npm command until you do, and step 2 will fail with the message "npm is not recognised". This catches almost everyone, so it is worth doing before you continue.

Everything in this step happens inside PowerShell, which is the terminal built into Windows. If you have never opened it before, here is exactly how.

How to open PowerShell
  1. Press the Windows key on your keyboard. The Start menu opens with a search box.
  2. Type the word powershell. You do not need to click anything first — just start typing.
  3. Press Enter, or click Windows PowerShell in the results.
  4. A blue or black window opens with a line ending in >. That blinking cursor is where commands go.
Pasting into PowerShell works with Ctrl + V as normal, and right-clicking pastes as well. If nothing appears when you paste, click once inside the window first so it has focus.

Now copy each line below using its Copy button, paste it into that window, and press Enter. Do them one at a time and wait for each one to finish before starting the next. Each command prints a few lines and then returns you to the > prompt, which is how you know it has completed.

npm install -g @google/gemini-cli
npm install -g freebuff
npm install -g @openai/codex
npm install -g supabase
npm install -g @slidev/cli

Here is what you have just installed. Gemini CLI is our main agent and gives us roughly 1,500 requests a day. freebuff and Codex are backups that each come with their own separate free limit, which matters because when one runs out we can switch to another instead of sitting idle. Supabase handles our database, and Slidev turns a plain text file into our presentation.

If you see "npm is not recognised", it means the restart in step 1 was skipped. Restart your PC and run the commands again.

Staying in the same PowerShell window, run the following command.

gemini

It will ask how you would like to authenticate. Use the arrow keys to move down the list, then press Enter on the second option rather than the first.

Our project — SIH26042

We are building the Vernacular Pedagogy and Real-Time Translation Tool for Government of Jharkhand: a teacher records or types a lesson in Hindi, and a child reads and hears it in their mother tongue. Here is everything the project itself needs on top of the setup above.

Total new installs: one npm package and one font. Everything else is already on your machine after the six steps above. That is why we chose this statement.

1 · Bhashini API key free · required

The Government of India's own language platform does all the translation, speech recognition and speech synthesis. We are not building AI — we are building the teaching tool on top of theirs.

Sign up, verify your email, then go to My Profile and generate a key. You need three values: userID, ulcaApiKey and an Inference API key.

Get a Bhashini key

2 · Noto Sans Ol Chiki easy to miss

Santali is written in the Ol Chiki script, and Windows does not ship a font for it. Without this, every translated word renders as an empty box and the demo dies in front of the judges.

It is free from Google Fonts. Add one line to index.html and set it as the font for any Santali text.

<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Noto+Sans+Ol+Chiki&display=swap">

3 · idb offline cache

A small wrapper around IndexedDB for caching lessons and audio so the app works with no connection. localStorage can hold the text, but audio files need IndexedDB.

npm install idb

Optional — an AI that works offline

This is only worth doing if you want a backup for when the venue wifi gives out, which in my experience it will at some point during the night.

LM Studio unlimited · offline

LM Studio runs an AI model entirely on your own laptop with no internet connection at all. Install it, then download the model called Nemotron 3 Nano 4B, which is about 2.8 GB.

Check your graphics card before you download anything. A 4 GB card can run a 3B or 4B model and nothing larger. The catalogue will cheerfully suggest 27B and 30B models that are 17 GB or more and can never load on our machines, so if it warns you that a model is "likely too large", please believe it.

The web toolkit — nothing to install

These all run in a browser tab, so there is no download and no setup beyond signing in. Please use the same Google account for every one of them, because sharing a design or a database project between us later becomes painful if we are scattered across different logins.

AI you can chat with

Gemini is our main assistant for thinking through problems and drafting text. There is no desktop app for Windows, so the browser is the only option.
ChatGPT works well as a second opinion. Please use the website rather than any desktop app you find, because the ones in the Windows package manager are all unofficial copies.
Google AI Studio is where your Gemini API key comes from, and where you can check how much of your daily quota is left.

Research and sources

Perplexity answers with its sources attached, which is exactly what we need for the presentation. Use Search mode rather than Work mode, as Work burns through the free allowance quickly.
NotebookLM lets you upload a long government PDF and then ask questions about it, answering with page numbers so every claim we make can be traced back.
The SIH portal carries the official rules, the timeline, and the published problem statements.

Design and prototyping

Stitch takes a plain-English description of a screen and designs it properly, including a mobile version. Remember to switch the toggle from App to Web before you generate anything.
Bolt takes a description of an entire app and builds a rough working version, which is genuinely useful in the first hour when we are staring at an empty folder.
Excalidraw is where we will draw the architecture diagram. Judges consistently respond to one clear picture of how the system fits together.
Photopea is a free Photoshop that runs in a tab, for any image editing the deck needs.

Database and backend

Supabase is our database and login system. One important detail: a free project goes to sleep after seven days of inactivity, so whoever owns it should open this dashboard on the morning of the demo to wake it up.
Neon is a second Postgres database we can use for throwaway experiments, and unlike Supabase it wakes itself up automatically.
GitHub holds our repository, and the submission link comes from here.

Indian data and languages our edge

Bhashini is the Government of India's own AI language platform, built by MeitY, covering 22 Indian languages for speech and translation. It is free with no rate limit, and using the government's own infrastructure at a government hackathon is an angle most teams will not have considered.
data.gov.in holds real government datasets covering agriculture, health, disaster management and more. Seeding our app with genuine data rather than invented rows is exactly what separates a prototype from a demo, and when we cite it we should name the dataset and year rather than just the portal.

Deploy, demo and compute

Cloudflare Pages gives us a free permanent web address for the finished app, which is far better on a slide than localhost.
Google Colab provides a free GPU in the browser, which we will need if any part of our solution involves training a model.
github.dev opens VS Code inside a browser tab, which is a useful escape route if someone's laptop dies on the day.

Things that will waste your time

Every one of these cost me real hours during setup, and none of them are obvious until they happen to you.

Gemini "Sign in with Google"
This no longer works for individual accounts. The login completes and then the account is refused. Use the API key option instead.
Restart after Node.js
If npm commands fail with npm is not recognised, the restart was skipped. Windows does not refresh its PATH until you restart.
Ad blockers break logins
An extension silently broke three separate Google logins during setup. If a sign-in button does nothing whatsoever when clicked, open the page in an incognito window.
Model size against VRAM
A 4 GB graphics card runs roughly a 3B or 4B model. Anything above about 3 GB will simply not load, however impressive it looks in the catalogue.
Convincing fakes everywhere
Searching the VS Code marketplace for Antigravity returns impostors with more installs than the real one, and there is no official ChatGPT or Gemini desktop app in winget either. Check the publisher rather than the install count.
npm create vite .
Scaffolding into a folder that already contains files will offer to delete them, and passing -y confirms that automatically. Scaffold into an empty subfolder and move the files up afterwards.
Async from the first line
If our data layer starts out synchronous, swapping in Supabase later means rewriting every file. Every store method should return a Promise from the very beginning.
RAM matters more than tools
Chrome with 28 tabs held 4.3 GB on my machine, which is more than every tool in this kit combined. Close your browsers before we start.
Do not install Docker
Nothing here needs it, and on a 16 GB laptop already running an editor and a dev server it will cause more problems than it solves.
